# 中職單場 Dashboard 規劃

## 使用流程

選日期、球隊與一二軍 → 選比賽 → 取得原始資料 → 整理事件並檢查品質 → 計算指標 → Dashboard → 下載原始 JSON、逐球 CSV 與分析結果。

已分析場次直接讀結果；重新整理時取得新快照並標示更新時間。第一版以已完成比賽為主，不承諾即時轉播。

## Dashboard

1. 比賽摘要：比分、逐局得分、球場、日期、主審。
2. 雙方比較：安打、三振、保送、用球等；先與官方單場成績核對。
3. 比賽走勢：累積比分與得分事件，不以比分折線冒充勝率曲線。
4. 投球分析：球種、球速、轉速、位置、揮空及球數情境。
5. 打擊分析：打席結果；擊球初速、仰角等待確認欄位覆蓋率。
6. 裁判分析：判決球點、分布；好球帶相符率待基準驗證後開放。
7. 明細與品質：逐球表、缺漏、分母、更新時間、資料及分析版本。

## 評分原則

- 區分原始數據、衍生指標與模型估計。
- 每個比率標明分母與樣本數；缺資料顯示無法計算，不填成零。
- 第一版不產生缺乏聯盟基準的 0–100 綜合評分。
- 保留原始值；正規化資料另存，方便追溯。
- 球點與好球帶不一致，不代表曾提出 ABS 挑戰或正式改判。

## 已知資料處理工作

- 排除換人等非投球事件。
- 還原投球前球數，另行核對出局、比分與壘況的事件前後語義。
- 建立結果分類，核對 BallinDirt、觸身等特殊事件。
- 核對座標單位、視角、球種自動及人工標籤差異。
- 與官方成績交叉驗證，保留差異紀錄。
- 樣本未見個人好球帶上下界與 ABS 挑戰結果，需另找來源。

## 開發里程碑

1. 選場、擷取、下載、摘要、逐球明細。
2. 投打圖表、比分走勢與篩選。
3. 裁判相符率與跨場比較。
4. 歷史資料、得分期望值、勝率模型；取得 ABS 事件後再加入挑戰統計。

驗收：選一場資料完整的已完賽場次，能下載原始資料、檢視 Dashboard，且主要統計與官方成績核對。三場樣本不足以推論全季覆蓋率。
