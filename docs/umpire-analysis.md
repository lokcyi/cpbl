# 主審判決分析

網站選場後開啟「主審判決」。全場摘要顯示模型相符率、非邊界相符率、邊界球與可評估覆蓋率；每位打者都有個人框、全場／各打席選擇與可點擊球點。可切換球隊、顯示揮棒等其他投球，並下載包含原始座標、換算座標、公式設定及身高來源的 JSON／CSV。

## 方法

- 個人框沿用官網顯示模型：下緣身高 × 27%，上緣 × 53.5%，左右各 21.58 cm；身高取官方球員 API，缺少時不評分。
- 預設將原始進壘位置沿官方多項式軌跡投影至官網中間平面（縱向 0.2159 m）。缺少軌跡／有效時間時不以其他平面混入評分。
- 球體投影圓與矩形框接觸視為模型好球；四角使用歐氏距離。預設球半徑 3.65 cm，可調或設為 0 使用球心模型。這是研究假設，未宣稱為中職 ABS 規則。
- 預設接觸邊界 ±2 cm 標示不確定。全場相符率仍包含這些球；另列排除邊界的相符率。調整後點「套用數值」。
- 僅評估未揮棒好壞球；界外、揮空、擊球、觸身等排除。官方文字與追蹤標籤矛盾者列為來源衝突，不任意選邊。
- 上方摘要始終為全場，下方球隊與打席選擇影響卡片和明細。每張圖自動縮放，點大小為示意；實際計算使用設定半徑。

這是公開資料與身高比例模型的相符度，不是正式裁判評鑑。沒有逐球姿勢量測、儀器誤差校準或正式 ABS 結果。身高是取得當時的名冊資料，不保證等於比賽當時資料。

## 球隊得利與受損

疑似誤判清單標示每球有利與不利球隊：模型好球卻判壞球，打擊方受益；模型壞球卻判好球，防守方受益。只計可評估、模型不符且非邊界的球；缺球隊資料保留未歸屬，不猜測球隊。

統計列出兩隊全場受益、受損、淨受益（受益減受損），另分打擊時及防守時受益。每球各讓一隊受益、另一隊受損；數字代表球數，未估算得分、勝率或實際勝負影響。表格不隨下方球隊／打席篩選改變，會隨模型設定重算。JSON 包含全場統計，JSON／CSV 每球含受益及受損歸屬。

## 已核對案例

2026-C-4，主審尤志欽，預設設定：197 顆未揮棒判決中 1 顆來源衝突；196 顆可評估，185 顆相符（94.4%）。27 顆邊界球；非邊界為 168/169（99.4%）。曾頌恩 11 局下打席 8 球中，5 顆為可評估判決，5 顆相符，另外 3 顆揮棒／界外不納入分母。

`npm test` 有 26 項測試，涵蓋原始比賽核對、獨立保存的 8 球中間平面數值、圓角幾何、分母、缺漏、衝突與匯出。瀏覽器核對球隊、打席、數值套用、球點明細及 390px 手機版無頁面橫向溢出。

## 資料與維護

`node scripts/collect-players.mjs` 收錄已保存比賽打者身高至 `data/players/index.json`。線上場次透過 `/api/players?id=2026-C-4` 取得相關打者資料，支援部分失敗並保留可用保存資料。`npm run refresh -- YYYY-MM-DD` 也會更新該批次打者。

官網實作研究與公式證據見 [official-strike-zone-findings.md](official-strike-zone-findings.md)。
